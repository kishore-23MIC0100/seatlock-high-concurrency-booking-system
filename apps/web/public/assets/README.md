# Event artwork

`neon-nights.jpg` uses the built-in ImageGen tool. The prompt requested a photorealistic indoor electronic music concert, silhouetted audience, a triangular cyan truss, violet lasers, magenta and blue spotlights, and a deep navy backdrop with no text or interface elements. The result was compressed for web use.

`afterglow.jpg` uses the built-in ImageGen tool with an intimate warehouse electronic show, a musician at a modular synthesizer, amber and orange spotlights, and soft smoke.

`midnight.jpg` uses the built-in ImageGen tool with an unoccupied microphone, oxblood curtains, a rose spotlight, and audience silhouettes in a comedy club.
